Lesezeichen

Der Snipebot läuft in einem Vinted-Tab und sucht von dort aus – mit deinem Browser und deiner Vinted-Sitzung, ohne Server. Gestartet wird er mit einem Lesezeichen, das du einmal anlegst.

  1. Unten auf Code kopieren tippen.
  2. In Safari diese Seite als Lesezeichen sichern: Teilen-Symbol → Lesezeichen hinzufügen, Name „snipetools“.
  3. Lesezeichen-Symbol (aufgeschlagenes Buch) → Bearbeiten → „snipetools“ antippen → die Adresse komplett löschen und den kopierten Code einfügen → Fertig.
  4. Snipebot starten: in snipetools auf Starten tippen, im Vinted-Tab die Adresszeile antippen und das Lesezeichen „snipetools“ wählen.
  1. Lesezeichenleiste einblenden (Strg+Umschalt+B bzw. ⌘+Umschalt+B).
  2. Den blauen Knopf snipetools unten mit der Maus in die Lesezeichenleiste ziehen.
  3. Snipebot starten: in snipetools auf Starten klicken, im neuen Vinted-Tab auf das Lesezeichen klicken. Die Angebote erscheinen dann hier in snipetools.
snipetools

Nach einem Update von snipetools zeigt der Snipebot „Lesezeichen veraltet“ – dann den Code einfach neu kopieren und im Lesezeichen ersetzen.

Filter

IDs aus der Vinted-URL

Filter auf Vinted einstellen und aus der Adresszeile ablesen: brand_ids[]=53 (Nike), catalog[]=1904, size_ids[]=207. Mehrere IDs mit Komma trennen.
